# STYLE.md — Sortes Visual Style Bible

**Canonical style prompt (reuse EXACTLY for every AI-generated asset):**

> "deep navy and gold, art nouveau mysticism, fine celestial linework, stars and
> moon phases, ornate gold filigree borders on a midnight blue field, elegant
> arcane symbolism, no text, no letters, no words"

Art direction rules for every asset:
- Color field: deep navy `#0A0E1A` / `#1A1F2E`, never flat black. Gold linework
  `#D4AF37`. Secondary accent mystic purple `#8B5CF6` only as glow/shadow.
- Motifs: crescent moons, star fields, sun rays, fine filigree borders,
  celestial charts, card-spread geometry. Casting-lots motif for the logo
  (dice/runes/stones feel via stars and dots).
- Linework: thin, precise, gold-on-navy, art nouveau curves. NOT photoreal,
  NOT cartoon, NOT flat-vector-minimal, NOT neon cyber.
- Consistency: same motif vocabulary across logo, icons, card back, hero art,
  OG image, favicons. If one asset drifts, regenerate it.
- No text/lettering in generated images (AI text renders badly); wordmarks are
  set in Cormorant Garamond in code.

Assets generated from this style (see README "Assets" section for files):
logo, app icons (192/512/maskable, WebP + PNG fallback), card back, hero
background, OG image 1200x630, favicon set.
