## Running migrations on staging (first, always)

```bash
# Local Postgres staging DB:
DATABASE_URL=postgres://sortes_test:sortes_test_local@localhost:5432/sortes_staging \
  npm run db:migrate

# Supabase staging (once the password is available via Secure Vault):
DATABASE_URL="postgres://postgres.rztkdkespxliddkdafok:<password>@aws-0-ap-northeast-1.pooler.supabase.com:5432/postgres" \
  npm run db:migrate
```

Rules:

- Migrations apply in version order, each in one transaction, and
  record themselves in `schema_migrations`. Re-running is a no-op.
- Never edit an applied migration file. A fix is a new numbered
  migration.
- The CLI refuses `NODE_ENV=production` without
  `SORTES_MIGRATE_PRODUCTION=1` — and production application still
  needs Velu's explicit approval for that specific run.
- Take a `pg_dump` before and after every migration apply
  (see `docs/BACKUP-RECOVERY.md`).

## Verification queries (run after every migration)

```sql
-- 1. Ledger: which versions applied, in order.
SELECT version, applied_at FROM schema_migrations ORDER BY version;

-- 2. Tables present (expect 7: users, auth_codes, transactions,
--    readings, reports, free_interpretations, free_readings).
SELECT table_name FROM information_schema.tables
WHERE table_schema = 'public' ORDER BY table_name;

-- 3. Indexes present (expect the 4 secondary indexes from 002).
SELECT indexname, tablename FROM pg_indexes
WHERE schemaname = 'public' AND indexname NOT LIKE '%_pkey'
ORDER BY tablename, indexname;

-- 4. Credit guard: the CHECK (credits >= 0) exists on users.
SELECT conname FROM pg_constraint
WHERE conrelid = 'users'::regclass AND contype = 'c';

-- 5. No double-encoded JSONB left (readings/reports data must be
--    objects, not JSON strings).
SELECT count(*) FROM readings WHERE jsonb_typeof(data) = 'string';
SELECT count(*) FROM reports WHERE jsonb_typeof(data) = 'string';
-- Both must be 0.

-- 6. RLS status (staging only; the RLS migration in
--    migrations/approval-required/ is NOT auto-applied).
SELECT tablename, rowsecurity FROM pg_tables
WHERE schemaname = 'public';
```
